CSS Usage

Example CSS variables usage in your stylesheets.

/* Apply the void background */
background-color: var(--bg-void);

/* Use accent colors with glow */
color: var(--accent-primary);
box-shadow: var(--accent-primary-glow);

/* Text hierarchy */
color: var(--text-primary); /* Headings */
color: var(--text-secondary); /* Body */
color: var(--text-tertiary); /* Captions */
